# PROJECT CONTEXT

Durable description of the project: what stays true between tasks. History of changes: `CHANGELOG_AI.md`; open work: `TASKS.md`; full design spec: `docs/PHASE-1-BLUEPRINT.md`.

## What it is
Polish site for BYKUCUTZZ Barbershop (Łódź, Drewnowska 49a, LU11), with a dark streetwear look and an LED-hexagon motif. Homepage conversion: booking on Booksy. `/cutz-academy`: a separate barber-training page, inquiries through official Instagram `@cutzzacademy`. `/polityka-prywatnosci`: privacy policy.

## Stack and commands
- Next.js 16 (App Router, TypeScript, Turbopack), React 19, Tailwind CSS v4, GSAP 3 (ScrollTrigger, SplitText, `@gsap/react`), `@phosphor-icons/react`; `sharp` and `potrace` for assets.
- `npm run dev` (port 3000), `npm run build`, `npm run start`, `npm run lint` (= `tsc --noEmit`, no ESLint), `npm run assets` (homepage assets; `npm run assets -- logo` re-traces only the BYKUCUTZZ logo), `npm run assets:academy` (Academy photos, logo and the Fade/Shape card crops, from untouched `assets-src`), `npm run assets:academy:videos -- "<folder with the mp4 originals>"` (Academy clips without re-encoding, posters, group still), `npm run assets:academy:logo` (traces the Academy mark into the inline SVG path).
- No automated tests: verification is lint, build and checks in a browser.

## Structure
- `src/app`: layout (fonts, JSON-LD, a boot script that sets `.js-motion` / `no-loader` before paint), homepage (section order), `cutz-academy/page.tsx` + scoped `academy.css`, privacy page.
- `src/components/academy`: `AcademyGallery` (hero photo strip), `AcademyVideos` (clip tiles), `ProgramMedia` (server-rendered plain Fade/Shape card photos, no overlays or dedicated animation), `AcademyCta` (every training inquiry).
- `src/components/sections`: Hero, Manifest, Salons, Pricing, Space, Team (Ekipa), Work, Reviews (the single social-proof section, `#opinie`), Crew, AcademyTeaser (homepage bridge to `/cutz-academy`, after Crew and before the Finale), Finale, Contact.
- `src/components/brand`: Logo, AcademyLogo (the supplied CUTZ ACADEMY mark), LedTrace + `led-traces.json` (LED geometry traced from the salon photos), HexGrid (procedural LED wall), HexGlyph. The illustrated industrial fittings (HexLamps, NeonSign, SteelChain, BarberTools) were removed on 2026-10-09 (PASS A1).
- `src/components/motion/MotionController.tsx`: the motion vocabulary, driven by data attributes (`data-reveal="lines|slide|fade|clip|rise|academy-hero"`, `data-led-draw`, `data-led-scrub`, `data-led-line`, `data-count`, `data-parallax` / `data-speed`).
- `src/data`: all content, typed. Facts are `verified` or `TO_PROVIDE`, never guessed; a published salon without its core facts fails the build. `academy.ts` uses client/profile-confirmed facts and a separate `academy-images.json` manifest.
- `src/styles/globals.css`: tokens (`--color-cyan` #61CCF0 is the CTA colour), type classes, section CSS.

## Conventions
- Motion runs only with `.js-motion` (absent under `prefers-reduced-motion` or without JS); then everything is visible and static.
- MotionController resolves each completed clip/LED timeline with its own ScrollTrigger refresh before creating subsequent triggers. This avoids a previously reproducible initialization error when reloading at a restored scroll position far down the homepage; reveal parameters remain unchanged.
- The hero loader plays once per browser session (`sessionStorage` `bk-loader`).
- The navbar is always visible (fixed to the top in both scroll directions); its background turns solid after the homepage hero and is solid from the start on subpages. One shared `Header` (and `MobileNavigation`) with two variants chosen by the route (`usePathname`, rendered on the server, no flash): the barbershop variant (BYKUCUTZZ logo, CUTZ ACADEMY logo link, salon links, "Umów wizytę" → Booksy) everywhere except `/cutz-academy`, which gets the Academy variant (Academy logo first, smaller BYKUCUTZZ logo as the link home, START / SZKOLENIA / PRAKTYKA / ZAPISY, "Zapytaj o szkolenie" → Instagram `@cutzzacademy`). Booksy is never the training CTA. Homepage anchors use `/#…` so they work from subpages. Anchor jumps land below it (`scroll-padding-top: var(--nav-h)`). z-index scale: nav 40 < mobile sticky booking bar 45 < mobile menu 60 < loader 100.
- Salon 02 is unpublished; development shows a clearly marked preview (`NEXT_PUBLIC_SALON_02_PREVIEW`).
- Read `AGENTS.md` before each task (`CLAUDE.md` points to it); update context, tasks and changelog after changes. The Phase 1 blueprint is a historical design proposal; this file and current code describe the implementation.
- Local preview: the main checkout runs `npm run dev`, and `http://localhost:3000` is the main test address for both the homepage and `/cutz-academy`. One agent edits a checkout at a time; the normal worktree integration rule is a deliberate merge (`AGENTS.md`). For the Academy integration on 2026-10-09, the client explicitly authorised selective local edits after backups and prohibited a Git merge; that exception has been completed without changing branches.
- Repository state: the integrated base is in main (PR #1/#2/#3). The main preview checkout uses feature/hex-3d-backgrounds (based on 9a87c6e; commit and push explicitly requested on 2026-10-09) with Claude's homepage work continued as the industrial visual system and both approved Academy corrections locally combined. Hero changes from feature/academy-readability-motion were applied selectively with explicit client authorisation and backups, without a Git merge or branch switch. The complete preview is http://localhost:3000/cutz-academy; the separate Codex code/port 3003 remain a reference version.
- No sitemap/robots files or production canonical domain are configured (`site.url` is null). Do not invent a deployment URL. No production deployment has been confirmed (no hosting configuration in the repository, no GitHub deployments); do not assume the site is live.

## CUTZ ACADEMY
- **Identity:** the light division of the brand. BYKUCUTZZ = black-dominant, white type, cyan; CUTZ ACADEMY = white-dominant, black type and graphic elements, Academy blue only as a detail. Same Archivo type, photography and precision; different environment. Do not bring the HexGrid, cyan glows or neon onto Academy, and do not bring the Academy palette onto the homepage.
- **Scope:** all Academy CSS lives in `src/app/cutz-academy/academy.css` under `.academy-theme` (the page wrapper around Header, main and Footer); `html:has(.academy-theme)` keeps the route's overscroll light. Tokens: paper `#F5F5F2`, white `#FFFFFF`, mist `#EAEAE6`, ink `#0B0C0D`, graphite `#3D4247`, muted `#61676D`, line `#D4D4CF`, Academy blue `#1A74A6` (on black `#6CB8E3`).
- **Logo:** `AcademyLogo` is an inline SVG path (`src/components/brand/academy-logo.json`, traced from the supplied transparent PNG by `npm run assets:academy:logo`), `fill="currentColor"`: black on Academy, white on the homepage navbar link and teaser. No raster logo at runtime; `public/images/academy/logo.png` is kept as the trace source.
- **Sections:** hero (`#start`: mark + "Szkolenia barberskie / Łódź", rule, H1 "Technika buduje przewagę." + description + black Instagram CTA and "Poznaj ofertę", then the 12-photo strip) → programmes (`#szkolenia`, Fade/Shape Control as alternating editorial rows) → clips (`#praktyka`, the one black band: one featured, three supporting) → formats (`#formaty`, Indywidualnie / W grupie) → inquiry (`#zapisy`: "Zapytaj o szkolenie.", the statement that details, dates and price are agreed on Instagram, @cutzzacademy, CTA) → BYKUCUTZZ relationship (`#prowadzacy`) → light Academy footer. Navbar: START / SZKOLENIA / PRAKTYKA / ZAPISY.
- **Navbar brand switch:** black CUTZ ACADEMY mark (current brand, larger) | divider | the original blue/cyan BYKUCUTZZ logo (smaller, links home), desktop and mobile; the Academy footer's "Część" + BYKUCUTZZ uses the same original blue/cyan logo. The blue BYKUCUTZZ logo is a deliberate exception to the Academy palette, never recoloured.
- **CTA system:** every training inquiry is `AcademyCta` → Instagram `@cutzzacademy` (black button, white type, small blue arrow); Booksy never appears on Academy. Secondary actions are underlined text links.
- **Media**, each used once: 12 post-training photos (strip), `academy5.jpg` (individual format, also the homepage teaser), a still of `academy2.mp4` (group format), 4:5 crops of `cut4.jpeg` / `cut6.jpeg` (programmes, plain photos), four silent clips.
- **Motion:** hero `academy-hero` entrance (0.35 s), headings `lines` once, photos `clip`, clips `fade`; strip loop/drag/arrows/pause unchanged; no LED ignition or glow. Reduced motion: native scroll strip, static content, clips start on click.
- No assumed prices, dates, duration, group size, syllabus, venue, instructors or certificates. Full audit and sources: `docs/CUTZ-ACADEMY.md`.

## Sections with custom behaviour (current state)
- **Booksy numbers (hero, Opinie, Crew):** one source, `site.stats` in `src/data/site.ts` (rating, reviews, five-star ratings, `asOf` shown in the footer, Booksy URL); never typed into components. Counters are displayed as confirmed minimums with a trailing "+" (`formatAtLeast`: "5098+", "5093+"); the 5,0 rating never gets one. In the Opinie block the "+" is a separate, smaller, raised cyan element so the count roll (4000 milestone → today's value, once) still reads a plain number. Once rolled, the main review count itself beats like a heart three times and then stays still (`.review-pulse`, CSS, 3 × 2.4 s: scale 1 → 1.08 → 1.015 → 1.11 → 1, then a pause), with a neon `#61ccf0` halo behind the digits (`.review-halo`, layered text-shadow) flaring on each beat and fading fast; started by `data-counted`, which `MotionController` sets when a count finishes. A small cyan heart inline before the thanks text (`.review-heart`) beats in lockstep with the number (one trigger and duration for both, same keyframes, slightly less scale). Only opacity/transform animate; nothing else in the section moves; static under reduced motion. "Dziękujemy za każde zaufanie." sits under the counter.
- **Manifest + salons intro:** procedural LED wall (`HexGrid`) that powers on with scroll; compact statements with a repeatable slide reveal.
- **Opinie (`Reviews`, `#opinie`): one social-proof section.** Former SocialProof + Opinie merged: 5098+ (roll, 3 beats), "opinii na Booksy", thanks line, 5,0 + five stars, 5093+ ratings, "Co piszą po wizycie" + two-row marquee (opposite directions, constant px/s, seamless, no controls, paused only offscreen, static wrap under reduced motion), then one "Umów wizytę" Booksy CTA (`#opinie-cta`). No repeated tagline statement.
- **Industrial fittings:** removed (2026-10-09, PASS A1): no hex lamps, tools, chains or sign. The LED identity is the real hero ceiling, the loader traces, the Manifest HexGrid (kept, to be evaluated separately) and the Finale LED line.
- **Mobile booking bar:** visible between the hero and the Finale, hidden over the salon panels, the reviews CTA, Finale and Kontakt. `--sticky-cta-h` (0 without the bar) drives `scroll-padding-bottom` and the footer's bottom padding.
- **Logos:** the BYKUCUTZZ SVGs (`public/images/brand/logo-*.svg`, viewBox 2288 x 784) and the CUTZ ACADEMY path (viewBox with a 16-unit safe area) contain the whole artwork with a small margin; logos are always sized by width with their natural ratio, never cropped by a wrapper. Visible copy uses no dash separators (hours read "10:00 do 14:30").
- **Socials and link language:** Instagram and Facebook live only in `site.socials` (Facebook: client-supplied profile URL, no handle). Kontakt is the main social destination (ruled rows); the footer has a small icon-only signature. Icons: Phosphor light only, cyan for functional/social icons, `ArrowUpRight` for external links. Secondary links share `.link-line` (muted base rule, cyan rule draws in on hover/focus, `.link-arrow` steps up-right, `.link-icon` lifts); Kontakt uses `.link-row`, the footer `.social-icon`, the navbar `.nav-link`. Buttons keep their fill swap. All movement is static under reduced motion.
- **Ekipa:** 8 portraits clipped to pointy-top hexagons (`clip-path`, never stretched). ≥1024 px: Byku's large hexagon on the left as the anchor; on the right the other seven as a honeycomb ring, one in the middle (Kacper) and six around it at equal distance. 768–1023 px: Byku as a wide row on top, the ring below. Phones: Byku as a wide lead row, crew in 2 columns. Name, verified review (none for Kasim: his only verified review is emoji-only) and its author sit under each portrait, followed by "Wybierz {imię} na Booksy" (general profile; "Umów się do …" only with a verified individual `bookingUrl`). A thin cyan LED outline powers on only while the pointer is over the hexagon itself or when the barber's Booksy link has keyboard focus.
